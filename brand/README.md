# brand/ — бренд VELIQ

| Папка / файл | Что внутри |
|---|---|
| `logo/` | Исходные SVG логотипа от владельца, **без изменений** (переименованы только файлы: `veliq3-*` → `veliq-*`). Словесный знак для светлого и тёмного фона, знак-символ обычный и инверсный. |
| `icons/app-icon.svg`, `.ico` | Иконка приложения: знак из логотипа на чёрной плитке. ICO содержит 16–256 px. |
| `icons/tray-{off,connecting,on,error}-{dark,light}.svg/.ico` | Иконки трея по состояниям, для тёмной и светлой панели задач. |
| `icons/favicon.svg`, `favicon.ico` | Значок сайта. |
| `icons/png/` | Все размеры в PNG (в том числе 180, 192, 512 для сайта и манифеста). |
| `social/og-image.png` | Картинка для ссылок (Open Graph), 1200 × 630. |
| `social/github-banner.png` | Баннер для README на GitHub, 1280 × 640, тёмный. |
| `social/github-social-preview.png` | Светлый вариант для Social preview репозитория. |
| `social/*.html` | Исходники картинок: правятся как HTML, растр — командой ниже. |
| `copy.md` | Все тексты: слоган, описания, тон, кнопки, состояния, ошибки, FAQ, установка в 3 шага. |
| `club-deck.md` | Презентация для владельцев клубов: структура 10 слайдов и тексты. |

## Пересборка растров

```bash
node design/tools/render-assets.mjs   # PNG из SVG и HTML (нужен playwright)
python3 design/tools/make-ico.py      # ICO из PNG (нужен Pillow)
python3 design/tools/build-tokens.py  # разложить свежие файлы по website/ и app-ui/
```

## Правила логотипа

- Используем файлы как есть: не перерисовываем, не меняем цвета, пропорции и прорезь.
- Светлый фон → `veliq-wordmark-light.svg`, тёмный → `veliq-wordmark-dark.svg`.
- Охранное поле — высота буквы V. Минимальная высота словесного знака — 16 px букв, знака — 20 px; меньше — иконка трея.
- Нельзя: на сигнальном оранжевом фоне, на градиентах и фото без подложки, растянутым или повёрнутым.

## Иконки трея

Состояние показано формой, а не только цветом: серый знак без линии — выключено, половина линии — подключение, полная линия — работает, красная точка — ошибка. Это единственное место, где знак показан без сигнальной линии.
