Установка VELIQ

VELIQ строит оптимальный маршрут для каждого соединения: заблокированное открывается, игры получают самый быстрый путь.

Windows один раз попросит права администратора — для службы, которая строит маршруты.

Готово

VELIQ установлен. Откройте программу и нажмите «Оптимизировать».

Не удалось установить службу

Windows не дала прав администратора. Запустите установку ещё раз и нажмите «Да» в окне Windows.
