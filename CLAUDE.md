# CLAUDE.md

Единый источник правил для всех агентов — **`docs/AGENT_RULES.md`** (запреты, инварианты, «НЕ переименовывать», структура, команды, порядок работы). Прочитай его целиком перед любой правкой.

Затем: `docs/handoff/PROTOCOL.md` (как работают два агента), `docs/handoff/CURRENT.md` (состояние и кто что делает).

Язык общения и сообщений коммитов: русский. Строки атрибуции в коммитах добавляет Claude Code по настройке сессии.

## Автоматический порядок работы Claude Code (владелец не напоминает)

Владелец хочет минимум участия. Субагенты лежат в `~/.claude/agents` (источник — ветка `claude/agents`). Делай без отдельной просьбы:

1. Владелец вставил отчёт Codex или написал «Codex запушил» → `git fetch` + `git pull --ff-only` в codex/work → **codex-reviewer**. Вердикт «сначала исправить» → сразу **codex-prompt** с готовым промптом для Codex. Вердикт «можно запускать» → **owner-commands** с одним блоком команд для владельца.
2. Владелец прислал лог, файл вывода или скриншот диагностики → **diag-analyst** → выводы + (если нужен фикс) готовый промпт через **codex-prompt** + (если нужна проверка) блок через **owner-commands**.
3. После итога Codex, когда в CURRENT.md нет статуса «В РАБОТЕ», и CURRENT.md длиннее ~150 строк → **handoff-archivist**.
4. Владельцу всегда отдавать только готовое к копированию: один промпт для Codex и/или один блок PowerShell. Не просить его искать файлы, выбирать варианты или помнить порядок.
