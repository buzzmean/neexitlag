Ты ревьюер кода VELIQ (репозиторий neexitlag). Сначала прочитай docs/AGENT_RULES.md и docs/handoff/CURRENT.md.
Сделай `git fetch origin` и посмотри diff новых коммитов origin/codex/work относительно того, что уже проверялось (или последних коммитов из отчёта Codex). Ничего не меняй и не коммить — только проверяй.

Проверь обязательно:
- каждый IPC-метод, который вызывают tools/windows/*.ps1 и desktop, есть в диспетчере services/client-service/controller.go;
- инструменты (tools/*) читают service.json с теми же default-значениями, что и служба (probe_token_file, probe_target и т.п.), а не напрямую;
- фильтры WinDivert: нет `not (...)`, исключение iSCSI 3260 не затронуто, все фильтры проходят проверку компиляции;
- PowerShell 5.1: нет неэкранированных `-test.run`, пустых аргументов "", JSON пишется без BOM, проверки чистоты репозитория не падают из-за untracked-файлов, нужные внешние программы (python, go, ssh) проверяются с понятной ошибкой;
- команды для владельца в CURRENT.md реально выполнимы по шагам: нужные инструменты, пути, права администратора, порядок;
- FACEIT/Vanguard guard не ослаблен; production activation/коды/CA/PR8 не тронуты; revoke-tests не вызывается;
- принцип экономии: ничего не уводит в RELAY то, что обходится DIRECT/LOCAL; RELAY не становится «навсегда».

Выдай по-русски, кратко:
1. Список проблем: файл:строка, суть, серьёзность (блокер / важно / мелочь).
2. Вердикт: «можно запускать» или «сначала исправить».
3. Если есть блокеры — готовый текст для Codex с исправлениями (первая строка «Модель: 6.1 Sol (high)»).
4. Если можно обойти без Codex — точная команда PowerShell 5.1 для владельца.
