# Протокол работы двух агентов (Claude Code и Codex)

Правила, запреты и инварианты — в `docs/AGENT_RULES.md`, они одинаковы для обоих агентов.

## Начало сессии
1. Прочитать `AGENTS.md` (или `CLAUDE.md`), `docs/AGENT_RULES.md`, `docs/handoff/CURRENT.md`.
   Читать только CURRENT; ARCHIVE — по необходимости через `rg -n` и узкий диапазон, не целиком.
2. `git fetch origin`, затем `git log -10` для каждой активной ветки (см. таблицу в CURRENT.md) и `git status`.
3. Показать владельцу 5 строк: цель, состояние, своя задача.

## Перед правкой
1. В таблице «Кто чем владеет» в CURRENT.md записать: агент, ветка, область файлов, дата. Закоммитить и запушить эту пометку.
2. `git pull` своей ветки. Если область файлов уже занята другим агентом, не начинать, а спросить владельца.
3. Два агента не работают над одними файлами одновременно.

## Ветки
- Рабочие ветки: `claude/<тема>` и `codex/<тема>`; базой берётся `claude/serene-cori-msra1u`.
- Слияния и PR только по явному «да» владельца. PR #8 и ветку `codex/direct-plus-flowseal` не трогать. Force-push и переписывание истории запрещены.
- Конфликт между ветками решает владелец, агент его не «разруливает» сам.

## Конец сессии
1. Перенести свой предыдущий итог дословно в `ARCHIVE.md` (новые сверху), архивировать закрытую подробную историю. Обновить `CURRENT.md` (≤150 строк): что сделано (хеши коммитов), что осталось, на чём остановился, какие команды запускать владельцу на ПК. Освободить свою строку в таблице владения.
2. Добавить в журнал решений новые решения (дата, решение, почему).
3. Соразмерные проверки и обязательный pre-push чек-лист из AGENT_RULES.md; коммит; `git push -u origin <ветка>`; показать `git log -1 --stat`.

## Что не писать в handoff
Секреты, токены, ключи, PEM, `ipc.token`, `identity.json`, `device.pem`, содержимое `diag-result.txt`. Допустимо: хеши коммитов, SHA256 бинарников, имена полей и команд.


## Компактность и проверки
- CURRENT хранит свежий итог, владение/очередь, действующие запреты и инварианты, открытые вопросы, «НЕ ПРОВЕРЕНО» и последние команды; максимум150строк.
- Освобождённые строки старше3дней свернуть в ссылку на ARCHIVE; историю не удалять и не переписывать. При сомнении оставить ограничение в CURRENT.
- Команды владельцу — один выполняемый блок `& { $ErrorActionPreference='Stop'; ... }` с папкой, правами, инструментами и проверкой native exit codes.
- Только документы → без тестовых прогонов; только скрипты → затронутые PS7/PS5.1 проверки; Go → полные race/vet/build Linux+Windows и Windows-фильтры. Подробный обязательный checklist — AGENT_RULES.md.
- Автоматический порядок Claude Code уже описан в корневом `CLAUDE.md` (20d8bd8); не дублировать и не откатывать его. Он не заменяет общие инварианты и разрешения владельца.
