# Шаблон начала сессии (для Claude Code и Codex)

Владелец вставляет в начале сессии:

```
Прочитай AGENTS.md, docs/handoff/PROTOCOL.md и docs/handoff/CURRENT.md, покажи по ним в 5 строках цель, состояние и свою задачу, потом выполняй.
```

Задачу владелец добавляет второй строкой. Claude Code дополнительно читает `CLAUDE.md` (он ссылается на тот же `docs/AGENT_RULES.md`).
