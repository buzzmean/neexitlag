## Known risks (tracked, not yet closed)

- Client certificates are issued for 30 days with no automatic renewal; the VPS server
  certificate generated by `tools/vps-provision` also has a 30-day lifetime.
  Expiry must be checked on the real deployment before it lapses.
- The Windows CI job can fail on `TestChromeSitesNativeAcceptance` when the read-only
  network inspection exceeds its 8 s budget. Failure details are now recorded in the
  snapshot error (duration, timeout flag, bounded stderr); the root cause on the
  runner is still to be confirmed from a new failing run.
- No benchmark or Internet latency improvement is claimed; see `BENCHMARKS.md`.
