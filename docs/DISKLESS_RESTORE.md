# Быстрое восстановление VELIQ на ПК с откатом (Langame)

Скрипты: `tools/windows/export-kit.ps1`, `restore-kit.ps1`, `apply-kit.ps1`. Проверены синтаксис и шифрование (PowerShell 7 на Linux: файл расшифровывается, с неверным паролем и после порчи одного байта отказ). На Windows не запускались.

## Идея
После отката ПК теряет всё: службу, `%ProgramData%\neexitlag`, GUI, настройки. Поэтому один раз с рабочей установки снимается «комплект»: один зашифрованный файл `veliq-kit.bin`. Его отправляете себе в Telegram вместе с `restore-kit.ps1`. После перезагрузки одна команда ставит всё из него.

## 1. Один раз: снять комплект
Рабочий ПК, PowerShell от администратора, под клубным пользователем, VELIQ закрыт через «Выход» в трее, папка репозитория:
```
& .\tools\windows\export-kit.ps1
```
Спросит пароль дважды (от 12 символов). На рабочем столе появятся `veliq-kit.bin` и `restore-kit.ps1`, оба отправить себе в Telegram.
В комплект попадают установленные `neexitlag-service.exe` и `VELIQ.exe`, WinDivert, учётные данные устройства, скрипты AUTO, которые лежат рядом с GUI, профили и выученные стратегии службы, а также `desktop.json`. Готовность Chrome (`browser-transport.json`) не переносится: политика Chrome в HKCU после отката пропадает, поэтому GUI активирует Chrome заново при первом включении оптимизации. Для всех файлов записывается SHA256. `ipc.token` не попадает: при установке выдаётся новый.
SSH-ключ для VPS: если в `%USERPROFILE%\.ssh` лежат `id_ed25519`, `id_ed25519.pub` (и `known_hosts`), они тоже уходят в комплект, только в зашифрованном виде. Если ключ хранится в другой папке, укажите её через `-SshDirectory 'D:\keys'`, а `-NoSsh` отключает перенос. При восстановлении ключ кладётся в `%USERPROFILE%\.ssh` с правами «владелец, SYSTEM, админы» (иначе OpenSSH его не примет). Уже лежащий там ключ не перезаписывается.
Шифрование: AES-256 и HMAC-SHA256, ключ получается из пароля через PBKDF2 (600 000 раундов). Используется встроенный .NET, без новых зависимостей. Открытые копии ключей лежат только во временной папке с доступом «админы + владелец» и удаляются сразу.

## 2. После каждой перезагрузки
Скачать оба файла из Telegram в «Загрузки». Открыть PowerShell от администратора:
```
Set-ExecutionPolicy -Scope Process Bypass -Force
Unblock-File "$HOME\Downloads\restore-kit.ps1"; & "$HOME\Downloads\restore-kit.ps1"
```
Ввести пароль. Этапы по порядку:
- DECRYPT: проверка целостности, затем расшифровка.
- KIT: сверка SHA256 всех файлов.
- Проверка WinDivert по закреплённым хешам 2.2.2-A и подписи драйвера.
- SERVICE: установка через штатный `install.ps1`.
- STATE: профили и стратегии.
- Проверка IPC `status`.
- DESKTOP: `install-desktop.ps1`.
- VERIFY: хеш службы совпадает с комплектом, служба Running.
- Запуск GUI без прав администратора.

Повторный запуск на уже восстановленном ПК ничего не меняет. Если стоит чужая версия службы или остался каталог без службы, скрипт останавливается и ничего не удаляет.

## Важно
- Пароль не пишите в Telegram. Без пароля файл бесполезен, с паролем это ключи вашего устройства.
- Один комплект подходит только для одного ПК. На другие ПК клуба его не копировать.
- После обновления службы или GUI комплект нужно снять заново.
- Внутри вызывается `install.ps1`, по правилам проекта его запуск только с разрешения владельца.
- Восстановление не доказывает, что сеть работает. Маршруты проверяются отдельно (`diag-no-vpn.ps1`).
