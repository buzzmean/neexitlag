Как установить

  1. Запустите VELIQ-Setup.exe

    Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае». Так бывает с новыми программами, которые Windows ещё не встречала.

  2. Разрешите установку службы

    Windows спросит права администратора один раз. Служба VELIQ строит маршруты и запускается вместе с системой.

  3. Нажмите «Оптимизировать»

    Программа откроется сама. После нажатия маршруты построятся сразу.

Компьютерный клуб? Для ПК с откатом после перезагрузки есть отдельная инструкция: установка в клубе.
